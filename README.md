# Website name here!

This is a basic HTML starter project you can build on however you like. The three main files that make up this site are index.html, sketch.js, and style.css. I also put a sound file in the audio folder and a graphics file in the images folder. 🦄

## Contents in a bit more detail

← `README.md`: That's this file, where you can tell people what your cool website does and how you built it.

← `index.html`: This is the main web page for your site. This particular HTML file doesn't do a lot. You'll see some references in the header to two JavaScript libraries (p5.js and Tone.js) that are loaded from CDNJS. You'll also see references to the local JavaScript and CSS files. Try clicking the image!

← `style.css`: CSS files add styling rules to your content. The CSS applies styles to the elements in the HTML page. But because the HTML page doesn't contain many elements in the body, there's not much for the CSS to do here.

← `sketch.js`: If you're feeling fancy you can add interactivity to your site with JavaScript. The code in the JavaScript file runs when the page loads, and when the visitor clicks the image.
